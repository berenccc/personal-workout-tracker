# Android APK (debug)

Личная сборка для установки на свой телефон. Внутри — текущий локальный трекер без экрана входа.

## Файл

- `Trainy-debug.apk` в папке проекта и на рабочем столе
- Сборка лежит в `C:\Users\galoz\trainy-apk\` (путь без кириллицы, так Gradle не падает)

## Установка на телефон

1. Скопируй APK на Android (кабель, Telegram себе, Google Drive, WhatsApp).
2. Открой файл на телефоне.
3. Разреши установку из этого источника, если система спросит.
4. Нужен интернет: AI идёт на Supabase, каталог и стили уже внутри APK.

Это debug-подпись. Для своего устройства нормально, в Play Store так не публикуют.

## Пересборка после правок сайта

```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
node tools/sync-android-web.js C:\Users\galoz\trainy-apk
Copy-Item capacitor.config.json C:\Users\galoz\trainy-apk\ -Force
Set-Location C:\Users\galoz\trainy-apk
npx cap sync android
Set-Location android
.\gradlew.bat assembleDebug
```

Готовый файл: `C:\Users\galoz\trainy-apk\android\app\build\outputs\apk\debug\app-debug.apk`

## Mi Band

Браслет сам не подключается к приложению. Цепочка такая: **Mi Band → Mi Fitness → Health Connect → этот трекер**.

1. В Mi Fitness: профиль → Health Connect → включи шаги, пульс, сон, **калории** и **тренировки**.
2. Поставь/обнови системное приложение Health Connect, если телефон спросит.
3. В трекере: Кабинет → Mi Band → Подключить → разреши чтение. Если спрашивает ещё калории/тренировки — тоже разреши.
4. На главном экране появится карточка браслета (сон, пульс покоя, шаги за день, калории). После «Завершить» к тренировке привяжутся пульс, зоны (жир / аэробная / анаэробная) и калории.

Шаги раньше могли быть нулями: Xiaomi пишет одну запись на весь день, а приложение смотрело только «до текущего момента». Теперь берётся полный день через aggregate.

Для живого пульса и зон на сессии запусти на браслете **Свободную тренировку** после старта в приложении.

Браслет отдаёт данные в Health Connect с задержкой, поэтому к моменту сохранения тренировки пульса может ещё не быть. Приложение само дочитывает сессию при следующем открытии (до 48 часов), а вручную — кнопка **Подтянуть с браслета** на вкладке «Браслет». Если цифры выглядят странно, разверни **«Что именно приходит из Health Connect»**: там видно количество записей, суммы и источник по каждому типу данных.

Разбор пульса по упражнениям и паузам строится по отметкам подходов: отмечай галочку сразу после подхода, иначе окна будут смазаны.

## Виджеты на рабочем столе

На Xiaomi / HyperOS обычный список виджетов часто **не показывает** сторонние Android-виджеты. Добавляй так:

1. Долгий тап по рабочему столу → **Виджеты** → **Приложения с виджетами** → **Все** → **Android-виджеты** → **Тренировки**. На HyperOS это самый надёжный путь.
2. Быстрый вариант: приложение → **Кабинет → Виджеты на рабочий стол** и нужный размер. HyperOS иногда криво создаёт виджет через запрос приложения — тогда удали его и добавь способом 1.

Если на виджете написано «Не удаётся загрузить виджет», сними его и поставь заново, а потом один раз открой приложение — оно перерисует все виджеты.

- **Старт** (2×1) — ближайшая тренировка и кнопка старта
- **Сессия** (2×2) — план, последний результат, старт
- **Неделя** (3×2) — точки дней, план, кнопки «Начать» и «Итог»
- **Обзор** (4×2) — план, сон с браслета, серия недель, результаты

Данные появляются после первого открытия приложения. «Начать» открывает трекер и стартует сессию, «Итог/Результаты» — последнюю тренировку в календаре.

Акцентный цвет виджетов повторяет цвет из **Кабинет → акцент**: кнопки и точки дней перекрашиваются сразу после выбора.

Фон переключается в **Кабинет → Виджеты на рабочий стол**: «Плотный фон» — тёмная карточка, «Прозрачный» — полупрозрачная подложка поверх обоев.

Xiaomi не даёт стороннему приложению нажать «Старт» на браслете. Поэтому «Начать тренировку» шлёт на Mi Band уведомление «Свободная тренировка»: его нужно один раз разрешить в Mi Fitness → уведомления → Тренировки, и на браслете останется одно касание.
